# 多中心随机分组测试系统

这是一个仅供流程测试的随机分组原型。管理员创建中心账号，中心账号录入患者并进行A/B组随机。

## 启动

需要 Python 3.9 或以上版本，不需要安装第三方包。

```powershell
python app.py
```

浏览器打开 http://127.0.0.1:8000 。

- 管理员账号由环境变量 `RCT_ADMIN_USERNAME` / `RCT_ADMIN_PASSWORD` 配置；未设置密码时首次启动会在控制台打印生成的随机密码。

管理员登录后可添加新的中心医生账号、指定中心和设置初始密码，并查看、导出全部中心数据。中心医生可录入脱敏研究编号、姓名缩写、性别、年龄和备注后执行随机，只能查看自己中心的数据。

数据保存在同目录的 `rct_clean.db`。随机以**医生账号**为单位分层：每个账号一条独立的置换区组序列（A/B 为 1:1，区组长度每次在 4 和 6 之间重新随机选择），当前区组用尽时自动生成下一个区组，不设固定总例数上限。库中只保存到当前区组，不预存未来序列；重启不会改变已产生的序列。

## Windows 免安装版

双击 `随机分组系统.exe`，程序会自动打开浏览器。使用结束后关闭程序的黑色窗口。数据库 `rct_clean.db` 会自动保存在 EXE 同一文件夹中，请将两者一起备份；不要在已有正式数据时删除或覆盖数据库。

## 重要限制

本版本只用于本机测试，不能直接用于正式临床试验或公网部署。正式使用前至少需要统计师确认随机方案、伦理及数据合规审查、HTTPS、正式账户管理、持久化会话、备份恢复、完整审计日志、服务器安全加固和验证测试。
